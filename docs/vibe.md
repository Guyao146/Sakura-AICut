# Vibe 动画创作与确认导出

## 使用

1. 在全局设置接入具备文本能力的模型。
2. 新建项目时选择「Vibe 直出」，输入主题、画幅和 3–150 秒目标时长。
3. 「创建并生成动画草稿」会提交后台任务，生成脚本 JSON 和内联动画页面，停在预览阶段，不会自动导出 MP4。关闭页面不会中断任务。
4. 启动隔离预览后可播放、暂停和拖动时间轴。工作台可编辑脚本 JSON / 动画 HTML，也可在 Agent 面板连续描述调整要求。Agent 读取当前稿与最近对话，通过 `vibe.revise` 提交草稿调整；脚本与代码一起校验保存，失败保留之前的稿件。
5. 如需配音，在全局设置接入语音模型，在工作台启用旁白配音。「加载可用音色」可选择当前账号的系统或自定义音色；未提供查询能力的接口可从服务控制台复制音色 ID。支持调整语速、音量和音调，填写短句并「生成音色试听」后保存。试听调用当前模型，可能产生费用，不保存媒体或修改项目版本。配音文本取各场次的 `narration`，可手动编辑或让 Agent 修改；音量、音调是否生效取决于接口。
   文件任务接口支持同步 T2A 语音模型：在设置中自行填写接口根地址、密钥及模型 ID，将模型能力设为语音并选为语音路由。音色查询使用同一账号，语速范围为 0.5–2。音色 ID 留空使用接口默认音色，也可在模型默认参数的 `voice_setting.voice_id` 中设置常用音色。
   「上传背景音乐」支持 MP3、WAV、M4A、AAC、FLAC、OGG，单文件最多 32 MiB。上传后可试听、调节音量、切换是否循环，再点击「保存音频设置」。音乐默认音量 20%，可与旁白混音；关闭旁白时也能单独使用音乐，无需语音模型。音乐超过视频时长时裁至结尾，不足时循环，关闭循环则补静音。移除音乐只移除当前选择，上传素材仍可重新选用。
6. 检查草稿后勾选「确认当前动画版本」，点击「确认并导出最终视频」。确认绑定内容版本；编辑脚本、代码、音色或音乐设置后必须保存并重新确认。最终成片为 MP4，可播放和下载；历史媒体不删除。旧队列中未确认的自动导出任务不会继续直出，需重新确认。
7. 任务中心每 3 秒刷新阶段、百分比、日志、错误和取消入口。Agent 的 `jobs.status` 可只读查询当前项目的最新任务进度与日志（查询时的快照，不是持续订阅）。动画修改任务和 Agent 规划任务分别展示，修改已排队后需在任务中心单独取消修改任务。取消后不保存迟到结果；已提交的模型调用可能仍计费。

适合动态图形、几何叙事、文字动画等；不下载外部视觉素材，也不保证模型第一次输出的代码可用。动画页面本身保持无声，配音和音乐在最终导出时由应用合成；音色与音乐可在设置区单独试听，当前草稿预览不包含混音。各场次配音短则补静音，略长则自动加速对齐（不超过 2 倍），过长明确失败并提示缩短旁白或延长场次，避免静默截断。配音逐次合成，重新导出可能再次产生语音调用费用。

## 帧协议

- 完整 HTML，仅内联 HTML/CSS/SVG/Canvas 与同步脚本。
- `window.__vibeMeta = { durationSec, fps: 24, width, height }`，必须与项目画幅和脚本总时长一致。
- `window.__vibeSeek(t)` 同步设置第 t 秒画面。相同 t 必须产生相同画面。
- CSS 自运行动画、真实时钟、异步寻帧、网络资源、嵌套页面均不支持。使用 Web Animations 时必须暂停并显式设置动画进度。
- 总帧数不得超过 3600，超过上限会报错，绝不截断为成功产物。

## 部署与隔离

Worker 镜像在构建时安装浏览器、运行库和中文字体。请随 compose 一起保留 `docker/render-seccomp.json`；该配置只额外支持非 root 浏览器建立用户命名空间，不需要特权容器或关闭沙箱。

每次渲染使用独立子进程、临时目录和新浏览器上下文。子进程不接收数据库路径与应用凭证；容器由 root 启动 worker 时，渲染子进程降为 UID/GID 1000。浏览器启用沙箱，限制网络、下载、权限与子页面。父进程监控取消、整体超时和停滞，失败时清理进程树及半成品。

预览需要主动点击，在 `sandbox="allow-scripts"` 的不透明来源 iframe 中运行，通过带令牌的 `postMessage` 寻帧，不允许同源访问。预览 CSP 阻断外部资源。浏览器层隔离不是抵御所有未知浏览器漏洞的保证；自托管管理员仍应保持运行时更新，不要把服务暴露给不可信匿名用户。

Linux 宿主机需要允许用户命名空间。若宿主策略禁用，任务会明确失败，不会降级关闭沙箱。本地开发安装命令：

```sh
pnpm --filter @sakura/worker exec playwright install --with-deps --only-shell chromium
```

## 验证

```sh
pnpm test
pnpm test:vibe:live
pnpm typecheck
pnpm check:brands
pnpm build
pnpm test:vibe:ui
```

`test:vibe:ui` 在构建后启动独立测试数据库、Web 和 worker，验证实际页面创建、取消、草稿生成不直出、隔离预览、编辑保存、确认失效及最终导出；不修改正常项目数据。

普通测试不要求浏览器。`test:vibe:live` 需要浏览器和 ffmpeg/ffprobe，使用本地模拟文本与语音模型，不调用付费服务；覆盖真实 MP4 帧数/尺寸/时长、画面变化、配音音轨和对齐、过长旁白拒绝、iframe 通信、网络拦截、错误、取消与死循环清理。
